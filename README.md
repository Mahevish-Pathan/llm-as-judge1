## LLM-as-Judge Evaluation Project
This project evaluates answers generated by one LLM using another LLM as a judge.

It uses:

1.A golden dataset of questions and expected answers
2.A generator LLM to create answers
3.A judge LLM to score generated answers against the golden answers
4.A CSV output file to store evaluation results

## How It Works
1.src/evaluator.py loads questions and golden answers from data/goldendataset.json.
2.For each question, generator_llm.generate_answer calls the generator model.
3.judge_llm.evaluate_answer sends the question, golden answer, and generated answer to the judge model.
4.The judge returns JSON scores for multiple evaluation dimensions.
5.evaluator.run_evaluation saves all results to data/evaluation_results.csv.
## Evaluation Metrics
The judge model scores each generated answer from 0 to 10 on:

1.Correctness
2.Relevance
3.Completeness
4.Faithfulness
5.Hallucination
6.Reasoning quality
7.Fluency and readability
8.Coherence
9.Safety and toxicity
10.Semantic similarity
## Prerequisites
Install Python 3.10 or later.

You also need a Groq API key.

## Setup
1. Clone or open the project
Open the project folder in VS Code.

2. Create a virtual environment
python -m venv .venv
Activate it:

On Windows:

.venv\Scripts\activate
On macOS/Linux:

source .venv/bin/activate
3. Install dependencies
pip install -r requirements.txt

## Environment Variables
Create a .env file in the project root:

GROQ_API_KEY=your_groq_api_key_here
MODEL1=your_generator_model_name
MODEL2=your_judge_model_name
Example:

GROQ_API_KEY=gsk_xxxxxxxxxxxxxxxxxxxxx
MODEL1=llama-3.1-8b-instant
MODEL2=llama-3.3-70b-versatile
MODEL1 is used by generator_llm.generate_answer.

MODEL2 is used by judge_llm.evaluate_answer.

## Generate the Golden Dataset
The repository already includes data/goldendataset.json.

To regenerate it, run:

python src/generate_dataset.py
This writes sample database-related questions and answers to data/goldendataset.json.

## Run the Evaluation
Run this command from the project root:

python src/main.py
src/main.py calls evaluator.run_evaluation.

The evaluation process will:

Read the golden dataset
Generate an answer for every question
Ask the judge LLM to score each generated answer
Print progress in the terminal
Save results to data/evaluation_results.csv

## Output
After running the project, results are saved in:

data/evaluation_results.csv
The CSV contains:

Column	             Description
question	        The input question
golden_answer	    The expected reference answer
generated_answer	The answer generated by the generator LLM
evaluation	        JSON score object returned by the judge LLM

## Main Files
src/main.py
Entry point for the project.

python src/main.py
src/evaluator.py
Contains evaluator.run_evaluation, which controls the full evaluation workflow.

src/generator_llm.py
Contains generator_llm.generate_answer, which calls the generator LLM.

src/judge_llm.py
Contains judge_llm.evaluate_answer, which evaluates generated answers.

It also contains judge_llm._parse_json_response, which parses the judge model response as JSON.

src/generate_dataset.py
Creates the sample golden dataset.

## Notes
Run commands from the project root because the code uses relative paths like data/goldendataset.json.
Make sure .env exists before running the evaluation.
The judge model is instructed to return only valid JSON.
If the judge response contains extra text, judge_llm._parse_json_response attempts to extract the JSON object.
## Troubleshooting
## Missing API key
If GROQ_API_KEY is missing or invalid, the Groq API call will fail.

Check your .env file:

GROQ_API_KEY=your_groq_api_key_here
## Output file not created
Make sure the data/ folder exists and run:

python src/main.py
## Import errors
Install dependencies again:

pip install -r requirements.txt
## Wrong working directory
Run the project from the root folder, not from inside
